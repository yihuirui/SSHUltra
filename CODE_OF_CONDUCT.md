# Code of conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

Everyone participating in this repository should be able to do so without harassment, regardless of experience level, background, identity or opinion. A friendly, patient tone makes it easier for new contributors to file their first issue or pull request.

## Expected behavior

- Show empathy and assume good faith when discussing a bug or a design choice
- Give and accept constructive, specific feedback about the code rather than the person
- Respect that maintainers have limited time and may say no to a change
- Keep technical discussions in the public thread so everyone has the same context
- Protect privacy: never paste credentials, host inventories or other people's data

## Unacceptable behavior

- Personal attacks, insults, derogatory comments, or sustained disruptive argument
- Publishing someone else's private information without explicit permission
- Sexualized language or imagery, and unwelcome sexual attention
- Repeatedly ignoring a maintainer's decision after it has been explained

## Scope

This applies to issues, pull requests, reviews, discussions and any public representation of the project. Security vulnerabilities are handled separately under [SECURITY.md](SECURITY.md).

## Reporting and enforcement

Report unacceptable behavior privately to the repository owner through their GitHub profile, or use GitHub's content-reporting flow; do not open a public thread about an allegation. Reports are reviewed confidentially and answered with a brief explanation of the outcome.

Maintainers may edit or remove content, close an issue or pull request, or temporarily or permanently block a participant. Actions are kept proportionate to the behavior, and a short explanation is recorded in the thread where possible.
