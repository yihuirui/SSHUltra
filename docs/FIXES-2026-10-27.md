| F6 代理／继承配置误导入直连 | OpenSSH 文件任意位置含 ProxyCommand、Include、Match 或通配 Host 时整体拒绝；拒绝全局连接字段继承和重复别名。JSON 原 ID 与显示名称分开映射，避免跳板引用碰撞。 |
| F7 凭据库损坏阻止启动 | 保留损坏源文件、禁用凭据库并提示；连接清单仍可使用。真实主进程入口和 Electron UI 验证显式切换“本次输入”可连接，损坏文件不被覆盖，不访问真实 Keychain。 |
| F8 SFTP 永久挂起 | 初始化／目录 15 秒截止，传输 30 秒无数据进展取消；UI 可取消当前会话全部文件操作并手动重试。隔离服务分别停止 INIT、REALPATH、READDIR、READ、WRITE 响应，验证超时／取消、请求与传输集合释放、重试、下载原文件保护及部分文件清理。 |
| F9 架构标签与程序不符 | 默认宿主架构；打包前后递归验证所有 Mach-O。当前 x64 运行时请求 ARM64 在创建输出前失败；最终 x64 包 16 个 Mach-O 均通过，禁止把复制的 x64 程序标为 ARM64。 |
| F10 凭据文档不一致 | SECURITY、README、架构与发行说明统一为默认内存使用、显式选择才持久化 Keychain 保护的密文，私钥内容不复制；故障恢复、迁移与 SFTP 取消行为同步说明。 |

SFTP 初始化尚未完成时，ssh2 没有暴露可单独取消的通道句柄；取消／超时将断开该 SSH 连接释放资源，保留滚屏供手动重连。已建立的文件通道取消保留 SSH shell；不会自动重发命令。失败上传可能留下远端部分文件，不自动删除。
